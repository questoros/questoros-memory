# Pre-existing Work Disclosure

QuestorOS existed before the hackathon as a broader AI workspace and personal operating-system project. It included internal memory capability and prior concepts for maintaining user, conversation, project, and workflow context.

The standalone project in this repository—**QuestorOS Memory: Agentic Memory as a Service**—did not previously exist as a separate implemented product or public service.

This repository contains new hackathon work that extracts and expands the memory concept into a portable platform for QuestorOS and third-party AI agents. The new work is intended to include the CockroachDB data model, distributed vector retrieval, AWS-hosted workflows, customer-facing MCP server, external interfaces, multi-tenant authorization, memory provenance, retrieval explanations, inspection controls, and a standalone demonstration.

Any code copied or adapted from pre-existing QuestorOS work must be identified by file and source commit before it is included here.
